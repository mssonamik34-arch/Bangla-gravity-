# Bangla Gravity

A 3D cartoon-style crazy physics platform game built with **Godot 4**.

## Current prototype
- First playable 3D obstacle-course level
- Character movement, jumping and physics collisions
- Moving/rotating hazard and elevated platforms
- Goal zone and basic level-clear feedback
- Godot 4 mobile-compatible renderer configuration

## Controls
- **WASD / Arrow keys:** Move
- **Space:** Jump
- **Android touchscreen:** On-screen directional buttons and Jump button

## Planned game
- 100+ offline levels with varied mechanics
- Offline and online multiplayer
- Bluetooth / same-Wi-Fi LAN multiplayer
- Coins, skins, secret characters and unlockable abilities
- Ice, Lava, Jungle, Space and Candy worlds
- Boss stages every 10 levels
- Endless, Time Attack and Challenge modes

## Run
Open this folder in Godot 4.2+ and press **F5**.

This is an early prototype. Android touch controls have been added to the code but still need on-device testing. Multiplayer networking, progression, audio, menus and Play Store release configuration are not implemented yet.
